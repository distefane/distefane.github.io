Bienvenido a Mis Cronómetros

Esta herramienta te permite registrar cuánto tiempo dedicas a diferentes actividades de forma sencilla.

¿Cómo funciona?

Puedes crear varios cronómetros y asignarle un nombre a cada uno.

Temporizador general

También puedes configurar una cuenta regresiva. Cuando llegue a cero, escucharás una alarma suave mientras la página permanezca abierta.

¿Qué puedes hacer?

  • Crear todos los cronómetros que necesites.
  • Iniciar y pausar cada cronómetro manualmente.
  • Tener varios cronómetros funcionando al mismo tiempo.
  • Editar el nombre de cada actividad.
  • Reiniciar un cronómetro cuando lo necesites.
  • Eliminar actividades que ya no quieras conservar.

Tu información se guarda automáticamente

Los cronómetros se guardan en este navegador.

Si un cronómetro queda activo, continuará contabilizando el tiempo aunque recargues la página.

Consejo: cuando cambies de actividad, pausa el cronómetro anterior e inicia el nuevo.
